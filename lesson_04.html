القيود والمفاتيح وأنواع البيانات

خلّي قاعدة بياناتك تحمي نفسها من الأخطاء بدل ما تعتمد على حسن نية المستخدم.

🎯 هتتعلم إيه في الدرس ده؟

  • الفرق بين PRIMARY KEY و FOREIGN KEY وكيف يعملان معًا.
  • أهم القيود: NOT NULL, UNIQUE, CHECK, DEFAULT.
  • اختيار نوع البيانات الصحيح لكل عمود.

🔑 المفتاح الأساسي (Primary Key)

المفتاح الأساسي يضمن أن كل سجل له معرّف فريد لا يتكرر أبدًا — مثل الرقم القومي، لا يمكن لشخصين أن يحملا نفس الرقم.

CREATE TABLE Students (
    StudentID INT PRIMARY KEY NOT NULL AUTO_INCREMENT,
    FirstName VARCHAR(50) NOT NULL,
    LastName VARCHAR(50) NOT NULL,
    EnrollmentDate DATE NOT NULL
);
الجزءالمعنى
PRIMARY KEYمعرّف فريد للسجل (لا تكرار)
NOT NULLلا يمكن ترك القيمة فارغة
AUTO_INCREMENTيزيد تلقائيًا 1، 2، 3... بدون كتابته يدويًا

🔗 المفتاح الأجنبي (Foreign Key)

يربط عمودًا في جدول بعمود آخر (غالبًا مفتاح أساسي) في جدول مختلف — أساس فكرة قواعد البيانات العلائقية.

CREATE TABLE Countries (
    CountryID INT PRIMARY KEY AUTO_INCREMENT,
    CountryName VARCHAR(50) NOT NULL UNIQUE
);

CREATE TABLE Astronauts (
    AstronautID INT PRIMARY KEY AUTO_INCREMENT,
    FirstName VARCHAR(50) NOT NULL,
    CountryID INT,
    FOREIGN KEY (CountryID) REFERENCES Countries(CountryID)
);
معلومة إضافيةهذا المبدأ اسمه العلمي Referential Integrity (سلامة الإحالة المرجعية)، وهو من أهم أسباب تفوّق قواعد البيانات العلائقية في حفظ اتساق البيانات على المدى الطويل مقارنة بتخزين البيانات في ملفات منفصلة غير مترابطة.

🛡️ أهم القيود (Constraints)

القيدالوظيفة
NOT NULLلا يقبل قيمة فارغة
UNIQUEكل القيم فريدة، لا تكرار
PRIMARY KEYNOT NULL + UNIQUE، معرّف السجل
FOREIGN KEYيربط بمفتاح أساسي في جدول آخر
CHECKيتحقق من شرط معيّن قبل القبول
DEFAULTقيمة افتراضية عند عدم التحديد
CREATE TABLE Missions (
    MissionID INT PRIMARY KEY AUTO_INCREMENT,
    MissionName VARCHAR(100) NOT NULL UNIQUE,
    LaunchDate DATE DEFAULT '2023-01-01',
    DurationDays INT CHECK (DurationDays > 0)
);

نصيحة للمحترفيناختيار النوع الصحيح مش شكلي، بيؤثر مباشرة على حجم قاعدة البيانات وسرعة الاستعلامات. القاعدة: اختر أصغر نوع بيانات يفي بالغرض فعليًا، ومتستخدمش TEXT لعمود اسم قصير مثلاً.

تمرين تطبيقي

  1. أنشئ جدول Books بعمود BookID مفتاح أساسي يزيد تلقائيًا.
  2. أضف عمود Price رقم عشري بدقة رقمين، ويجب أن يكون أكبر من صفر (استخدم CHECK).
  3. أضف عمود IsAvailable قيمة منطقية افتراضيتها TRUE.
