نظرة عامة على SQL

فيديو شرح: كيف تبدأ التعلم
يغطي أول 7 دروس من المسار — هيتضاف رابط اليوتيوب قريبًا

SQL (اختصار Structured Query Language) هي اللغة اللي بتتكلم بيها مع أي قاعدة بيانات علائقية — سواء عايز تجيب بيانات، تضيف، تعدّل، أو تحذف. مش لغة برمجة بالمعنى التقليدي زي Python أو Java؛ SQL لغة تصريحية (Declarative) — يعني انت بتقول لقاعدة البيانات "عايز إيه" مش "إزاي توصله".

ليه SQL بالذات مهمة جدًا في مسارك؟ لأنها القاسم المشترك بين كل محركات قواعد البيانات تقريبًا — سواء بتشتغل على SQL Server، PostgreSQL، MySQL، أو Oracle، أنت هتكتب استعلامات SQL في كل الحالات دي، مع فروق بسيطة هنوضحها أول بأول.

SQL المعياري و"لهجات" المحركات

فيه معيار عام اسمه ANSI SQL، لكن كل محرك بيضيف عليه امتدادات خاصة بيه:

SQL ServerT-SQL — امتدادات زي TOP, IDENTITY
PostgreSQLأقرب محرك للمعيار، بيدعم ميزات متقدمة زي JSONB
MySQLبسيط وسريع، بعض الاختلافات في التعامل مع الـ Strings
OraclePL/SQL — لغة إجرائية كاملة فوق SQL الأساسية

مفهوم غلط شائع عند المبتدئين

"SQL لازم أتعلمها زي أي لغة برمجة، خطوة بخطوة بالترتيب"

الحقيقة إن SQL أبسط بكتير من كده — مش محتاج تفهم Loops أو Functions معقدة عشان تبدأ. أول استعلام مفيد ممكن تكتبه في أول 10 دقايق من التعلم. المشكلة اللي بتحصل فعلاً إن ناس كتير بتحاول تحفظ الأوامر من غير ما تجرّبها على بيانات حقيقية، فتنساها بسرعة.

الأدوات اللي هتحتاجها

مش محتاج تثبّت حاجة معقدة عشان تبدأ. في الدرس الجاي ("تجهيز بيئة العمل") هنوريك إزاي تشغّل أول قاعدة بيانات بتاعتك في أقل من 10 دقايق.

تمرين سريع

قبل ما تكمل للدرس الجاي، جاوب على نفسك: لو عندك جدول اسمه employees وعايز تعرف أسماء كل الموظفين بس، هل الأمر ده "أمر تصريحي" (بتقول عايز إيه) ولا "أمر إجرائي" (بتقول إزاي توصله)؟ الإجابة هتفهمها أكتر في درس "كتابة أول استعلام".

الخلاصة: SQL لغة واحدة، لكن معاها "لهجات" مختلفة بحسب المحرك. احنا في المسار ده هنعلّمك SQL بشكل يخليك قادر تشتغل على أي محرك منهم براحتك.
