الاستعلامات المتقدمة Subqueries · Views · Index

آخر محطة في المسار — أدوات المحترفين لتنظيم وتسريع قاعدة بياناتك.

🎯 هتتعلم إيه في الدرس ده؟

  • كتابة استعلامات فرعية داخل SELECT وUPDATE وDELETE.
  • إنشاء واستخدام الـ Views لتبسيط الاستعلامات المعقدة.
  • فهم الفهرسة (Index) ومتى تستخدمها ومتى تتجنبها.
  • دمج نتائج عدة استعلامات باستخدام UNION وINTERSECT.

🪆 Subquery — الاستعلام الفرعي

استعلام داخل استعلام آخر، محاط بأقواس، يكون عادةً على يمين عامل المقارنة. الاستعلام الخارجي يُسمى Main Query، والداخلي يُسمى Subquery.

-- مع SELECT
SELECT * FROM EMPLOYEE
WHERE ID IN (SELECT ID FROM EMPLOYEE WHERE SALARY > 4500);

-- مع UPDATE
UPDATE EMPLOYEE
SET SALARY = SALARY * 1.25
WHERE AGE IN (SELECT AGE FROM CUSTOMERS_BKP WHERE AGE >= 29);
ملاحظة مهمةلا يمكن استخدام ORDER BY داخل الاستعلام الفرعي مباشرة، لكن يمكن استخدام GROUP BY لتحقيق تأثير مشابه.
معلومة إضافيةالاستعلامات الفرعية قوية لكنها أحيانًا أبطأ من البديل باستخدام JOIN، خصوصًا على جداول كبيرة. القاعدة العملية: لو الاستعلام الفرعي بيرجع قائمة طويلة من القيم، فكّر في تحويله لـ JOIN وقارن الأداء.

👁️ Views — العروض

الـ View هي «جدول افتراضي» مبني على نتيجة استعلام محفوظ، تقدر تستخدمه كأنه جدول عادي دون تكرار كتابة نفس الاستعلام المعقد كل مرة.

CREATE VIEW DetailsView AS
SELECT NAME, ADDRESS
FROM Student_Details
WHERE STU_ID < 4;

SELECT * FROM DetailsView;
DROP VIEW DetailsView;
لماذا الـ Views مفيدة؟أولًا: الأمان — تقدر تديها للمستخدمين وصول لأعمدة معينة فقط بدون كشف الجدول الأصلي كاملًا. ثانيًا: التبسيط — تخفي تعقيد استعلام كبير بيحتوي عدة JOINs خلف اسم بسيط يستخدمه أي شخص في الفريق.

⚡ Index — الفهرسة

الفهرس أداة لتسريع عمليات البحث (SELECT) بشكل كبير، تمامًا مثل فهرس آخر صفحات كتاب.

CREATE INDEX index_name ON table_name (column1, column2);
CREATE UNIQUE INDEX websites_idx ON websites (site_name);
DROP INDEX index_name;
الميزة لها ثمنالفهرس يسرّع القراءة (SELECT)، لكنه يبطّئ الكتابة (INSERT/UPDATE) لأن قاعدة البيانات لازم تحدّث الفهرس مع كل تعديل. ضع فهارس فقط على الأعمدة المستخدمة كثيرًا في WHERE أو JOIN أو ORDER BY.

🎓 خلاصة الدورة

بكده تكون غطيت الأساسيات الكاملة للتعامل مع أي قاعدة بيانات علائقية: من إنشاء الجداول، للاسترجاع والتصفية والترتيب، للدوال التجميعية، للقيود وأنواع البيانات، لربط الجداول، وصولًا للاستعلامات المتقدمة والـ Views والفهرسة.

الخطوة التالية المقترحة

  1. صمّم قاعدة بيانات كاملة لمشروع بسيط بنفسك (نظام حجز مواعيد، أو متجر إلكتروني صغير).
  2. طبّق فيها كل ما تعلمته من الجداول المترابطة حتى الاستعلامات المركبة.
  3. شاركني تصميمك عبر واتساب أو الإيميل لو عايز مراجعة!
