مقدمة إلى قواعد البيانات و SQL

في هذا الدرس هتفهم إيه هي البيانات، إيه هي قاعدة البيانات، إيه هي لغة SQL، وهتجهّز بيئة العمل اللي هنشتغل بيها طول الدورة.

1. مفهوم البيانات

البيانات (Data) هي المعلومات على اختلاف أنواعها — نصوص، أعداد، تواريخ، صور، فيديوهات، وغيرها.

الفرق الأساسي بين المعلومات والبيانات: المعلومات مفهومة مباشرة للبشر، أما البيانات فهي الشكل الذي تفهمه البرامج والآلات، ولا تكون ذات قيمة فعلية إلا بعد معالجتها واستخراج المعلومات منها.

2. مفهوم قواعد البيانات

قاعدة البيانات (Database) هي ملف ضخم يُخزَّن فيه البيانات بشكل مرتب ومنظم، بحيث يمكن استرجاعها والتعديل عليها في أي وقت. أهميتها إنها بتخليك تدير بيانات المستخدمين في مكان واحد بسهولة.

💡 ليه قواعد البيانات مهمة؟

أي موقع أو برنامج أو لعبة بتستخدمها دلوقتي — حتى الصفحة اللي بتقرأها الآن — بتحفظ بياناتها في قاعدة بيانات. من غيرها، مفيش طريقة منظمة لحفظ واسترجاع ملايين السجلات بسرعة.

بشكل عام، قاعدة البيانات بتتيحلك:

  • ترتيب بيانات المستخدمين بشكل يسهل الوصول والتعامل معها.
  • تحديد أنواع البيانات المخزّنة بدقة (نصوص، أرقام، تواريخ، عملات...).
  • وضع شروط على البيانات المخزّنة، وإمكانية وضع قيم افتراضية.
  • الوصول السريع جدًا للمعلومات عند استخدام الفهارس (Indexes).
  • منع تكرار تخزين المعلومات — من أهم مميزاتها.
  • إنشاء نسخ احتياطية (Backups) لاستعادتها عند حدوث أي خطأ أو اختراق.

3. ما هو SQL؟

SQL اختصار لـ Structured Query Language، وهي مجموعة أوامر تتعامل بيها مع قواعد البيانات. أوامرها بتتقسم لخمس فئات رئيسية:

  • DDL (Data Definition Language) — تصميم وتعديل قواعد البيانات.
  • DQL (Data Query Language) — استرجاع البيانات.
  • DML (Data Manipulation Language) — معالجة البيانات الموجودة.
  • DCL (Data Control Language) — إدارة صلاحيات المستخدمين.
  • TCL (Transaction Control Language) — التحكم في تنفيذ الاستعلامات والنسخ الاحتياطية.

✅ خبر كويس

المفاهيم والأوامر اللي هتتعلمها في هذه الدورة نفسها موجودة في كل قواعد البيانات المشهورة (MySQL، SQL Server، Oracle، إلخ). لما تتقن نوع واحد، هتقدر تتعامل مع الباقي بسهولة.

4. كيف يتنفذ الاستعلام؟

أي أمر SQL بيتم إرساله لقاعدة البيانات بيُسمى استعلام (Query). الاستعلام مبيتنفذش مباشرة، بل بيمر بالخطوات دي:

  1. خادم قاعدة البيانات (Database Server) بيفسّر الأوامر الموجودة في الاستعلام.
  2. لو الأوامر مكتوبة صح، بينفذها ويرجع النتيجة.
  3. لو فيه خطأ، الخادم بيرجعلك رسالة توضح سبب المشكلة عشان تصححها.

5. تجهيز بيئة العمل

هنستخدم في هذه الدورة قواعد بيانات MySQL لأنها مجانية ومن أشهر قواعد البيانات المستخدمة. عشان نشتغل بيها، هنركّب برنامج XAMPP اللي بيوفر خادم MySQL بالإضافة إلى لوحة تحكم phpMyAdmin للتعامل المباشر مع قواعد البيانات.

6. التعليقات في SQL

التعليقات (Comments) بتُستخدم لوضع ملاحظات أو شروحات حول الاستعلامات المعقدة، عشان لما ترجعلها بعد فترة تفهمها بسرعة. مفسّر الاستعلامات بيتجاهل التعليقات تمامًا ومبتأثرش على تنفيذ الأوامر.

في MySQL فيه ثلاث طرق لوضع تعليق:

تعليق سطر واحد بـ --

SELECT * FROM products -- إجلب كل معلومات المنتج
WHERE id = 3;          -- الذي يملك رقم id يساوي 3

تعليق متعدد الأسطر بـ /* */

/*
  هذا الاستعلام يقوم بجلب معلومات طالب
  من جدول students وجدول marks
*/
SELECT s.studentid, s.name, s.total_marks
FROM student s, marks m
WHERE s.studentid = m.studentid
AND m.total_marks > 80;

ملاحظة

مش كل قواعد البيانات بتدعم التعليقات (مثلاً Access مبتدعمهاش)، وطريقة كتابتها بتختلف من قاعدة بيانات لأخرى.

📌 خلاصة الدرس

  • البيانات هي معلومات مفهومة للآلات، وقاعدة البيانات هي المكان المنظم لتخزينها.
  • SQL هي اللغة اللي بنتعامل بيها مع قواعد البيانات، وأوامرها مقسّمة لـ 5 فئات (DDL, DQL, DML, DCL, TCL).
  • هنستخدم MySQL و XAMPP و phpMyAdmin طول الدورة.
  • التعليقات بتساعدك تفهم كودك القديم بسرعة، وبيها 3 طرق في MySQL.
