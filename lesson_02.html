الاستعلام والتصفية SELECT · WHERE · ORDER BY

تعلم إزاي تسحب بالظبط البيانات اللي محتاجها من وسط آلاف السجلات.

🎯 هتتعلم إيه في الدرس ده؟

  • استخدام WHERE للفلترة بكل عوامل المقارنة.
  • البحث بنمط معيّن باستخدام LIKE.
  • ترتيب النتائج وتحديد عددها بـ ORDER BY و LIMIT.

هنستخدم في هذا الدرس جدول أفلام للتدريب:

CREATE TABLE Movies (
    ID INT PRIMARY KEY,
    Title VARCHAR(255),
    Genre VARCHAR(50),
    ReleaseYear INT,
    Rating DECIMAL(3,1)
);

🔍 WHERE — فلترة النتائج

SELECT * FROM Movies WHERE Genre = 'Action';
SELECT * FROM Movies WHERE ReleaseYear > 2000;
SELECT * FROM Movies WHERE Rating <= 8.0;
SELECT * FROM Movies WHERE ReleaseYear BETWEEN 1990 AND 2000;
عامل المقارنةالمعنى
=يساوي
!= أو <>لا يساوي
> / <أكبر / أصغر من
>= / <=أكبر أو يساوي / أصغر أو يساوي
BETWEEN x AND yبين قيمتين شامل الطرفين
معلومة إضافية: AND / OR / NOTتقدر تجمع أكثر من شرط في نفس الاستعلام: AND لازم كل الشروط تتحقق، وOR يكفي شرط واحد. مثال: WHERE Genre='Action' AND Rating>8.5

🔤 LIKE — البحث بنمط معيّن

SELECT * FROM Movies WHERE Title LIKE 'The%';   -- يبدأ بـ The
SELECT * FROM Movies WHERE Title LIKE '%Man%';  -- يحتوي على Man

الرمز % يعني أي عدد من الأحرف، والرمز _ يعني حرف واحد بالضبط.

📊 ORDER BY — الترتيب

SELECT * FROM Movies ORDER BY ReleaseYear;       -- تصاعدي (افتراضي)
SELECT * FROM Movies ORDER BY ReleaseYear DESC;  -- تنازلي

🔢 LIMIT — تحديد عدد النتائج

SELECT * FROM Movies ORDER BY ReleaseYear DESC LIMIT 3; -- أحدث 3 أفلام
نصيحة للمحترفينORDER BY مع LIMIT هي الطريقة القياسية لعمل «Top 10» في أي تقرير أو Dashboard. في SQL Server تحديدًا تُستخدم TOP بدل LIMIT: SELECT TOP 3 * FROM Movies ORDER BY ReleaseYear DESC;

تمرين تطبيقي

  1. اعرض كل الأفلام من نوع Sci-Fi فقط.
  2. اعرض الأفلام بين 1994 و2010 مرتبة من الأحدث للأقدم.
  3. اعرض أعلى فيلمين تقييمًا فقط.
