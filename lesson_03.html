الدوال التجميعية GROUP BY · HAVING

حوّل مئات الصفوف لأرقام وملخصات مفيدة بضغطة زر.

🎯 هتتعلم إيه في الدرس ده؟

  • استخدام COUNT, SUM, AVG, MIN, MAX.
  • تجميع البيانات حسب فئة معينة باستخدام GROUP BY.
  • الفرق العملي بين WHERE و HAVING.

جدول التدريب:

CREATE TABLE Sales (
    SaleID INT PRIMARY KEY,
    ProductID INT,
    Quantity INT,
    Price DECIMAL(10,2),
    SaleDate DATE
);

🧮 الدوال التجميعية الخمس الأساسية

الدالةالوظيفة
COUNT(*)عدد السجلات
SUM(col)مجموع القيم
AVG(col)متوسط القيم
MIN(col)أصغر قيمة
MAX(col)أكبر قيمة
SELECT COUNT(*) AS TotalSales FROM Sales;
SELECT SUM(Quantity) AS TotalQty FROM Sales;
SELECT AVG(Price) AS AvgPrice FROM Sales;

🗂️ GROUP BY — التجميع حسب فئة

تخيل أنك مسؤول مكتبة وعايز تصنّف الكتب حسب النوع ثم تحسب عدد كل نوع — هذا بالضبط ما تفعله GROUP BY.

-- مجموع الكمية المباعة لكل منتج
SELECT ProductID, SUM(Quantity) AS TotalQuantitySold
FROM Sales
GROUP BY ProductID;

-- عدد مرات بيع كل منتج
SELECT ProductID, COUNT(*) AS NumberOfSales
FROM Sales
GROUP BY ProductID;

القاعدة الذهبية: أي عمود تكتبه في SELECT ولم تستخدمه داخل دالة تجميعية، لازم يكون موجودًا في GROUP BY.

🧹 HAVING — فلترة المجموعات

WHERE بتفلتر الصفوف قبل التجميع، أما HAVING بتفلتر المجموعات بعد التجميع.

SELECT ProductID, COUNT(*) AS NumberOfSales
FROM Sales
GROUP BY ProductID
HAVING COUNT(*) > 2;
ترتيب الجملة الكاملة (احفظه)SELECT ... FROM ... WHERE ... GROUP BY ... HAVING ... ORDER BY ... — لو حاولت تستخدم COUNT() داخل WHERE هتاخد خطأ، لازم تستخدمها في HAVING لأن WHERE بتتنفذ قبل التجميع.

تمرين تطبيقي

  1. احسب إجمالي عدد السجلات في جدول Sales.
  2. احسب أعلى وأقل سعر مسجّل.
  3. اعرض كل منتج مع إجمالي ما بيع منه، لكن فقط المنتجات التي بيعت بكمية إجمالية أكبر من 10.
➡️ السابق SELECT و WHERE و ORDER BY التالي ⬅️ أنواع البيانات والقيود والمفاتيح
