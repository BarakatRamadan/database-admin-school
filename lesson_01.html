مقدمة إلى قواعد البيانات و SQL

الأساس اللي لازم تفهمه قبل ما تكتب أي سطر SQL في حياتك.

🎯 هتتعلم إيه في الدرس ده؟

  • الفرق بين قاعدة البيانات والجدول والعمود والصف.
  • ليه محتاجين لغة استعلام أصلاً زي SQL.
  • تكتب أول أمر CREATE TABLE و INSERT و SELECT بنفسك.

🤔 ما هي قاعدة البيانات؟

قاعدة البيانات هي مجموعة منظمة من المعلومات يمكن الوصول إليها وإدارتها وتحديثها بسهولة. تخيّلها كحافظة ملفات إلكترونية كبيرة:

المفهومتشبيه بسيط
قاعدة البيانات Databaseالحافظة نفسها
الجدول Tableمجلد داخل الحافظة، مثلاً «الأصدقاء»
العمود Columnنوع معيّن من المعلومات (الاسم، الهاتف)
الصف Rowورقة داخل المجلد، بيانات شخص واحد

🧩 لماذا نحتاج لغة استعلام؟

قواعد البيانات الحديثة معقدة وتحتوي عشرات الجداول المترابطة، فكان لازم نلاقي واجهة موحدة نتعامل بيها مع هذا الكم من البيانات بكفاءة — وهنا يجي دور SQL.

💻 ما هي SQL؟

SQL اختصار لـ Structured Query Language (لغة الاستعلام الهيكلية)، وهي اللغة القياسية للتعامل مع قواعد البيانات العلائقية. بتمكّنك من استعلام البيانات، إدخالها، تحديثها، حذفها، وإدارة هيكل قاعدة البيانات نفسها.

معلومة إضافيةكل أنظمة إدارة قواعد البيانات الكبرى — MySQL، PostgreSQL، SQL Server، Oracle، وحتى SQLite في تطبيقات الموبايل — تستخدم SQL كلغة أساسية، مع اختلافات بسيطة تُسمى «لهجات» (Dialects). لو أتقنت الأساسيات هتقدر تتنقل بين أي قاعدة بيانات بسهولة.

🛠️ أول جدول لك

CREATE TABLE Friends (
    FirstName VARCHAR(50),
    LastName VARCHAR(50),
    PhoneNumber VARCHAR(15),
    Email VARCHAR(100)
);

CREATE TABLE Friends ننشئ جدول جديد، وكل سطر بعدها هو تعريف عمود: اسم العمود ثم نوع البيانات اللي هيخزّنه. VARCHAR(50) يعني نص متغير الطول بحد أقصى 50 حرف.

➕ إدخال البيانات

INSERT INTO Friends (FirstName, LastName, PhoneNumber, Email)
VALUES
('Ali', 'Al-Ahmad', '123456789', 'ali@example.com'),
('Sara', 'Ahmad', '987654321', 'sara@example.com'),
('Mohamed', 'Al-Tayeb', '456123789', 'mohamed@example.com');

🔍 استرجاع البيانات

SELECT * FROM Friends;
أسئلة شائعةهل لازم أكتب الأوامر بحروف كبيرة؟ لا، SQL مش حساسة لحالة الأحرف، لكن الاصطلاح الشائع كتابة الكلمات المفتاحية بحروف كبيرة لتمييزها. وبالنسبة لعلامات الاقتباس: استخدم دائمًا العلامة المفردة ' للقيم النصية لتفادي أي التباس.

جرّب بنفسك الآن

  1. افتح db-fiddle.com وأنشئ جدول Friends بنفس الأعمدة أعلاه.
  2. أدخل بياناتك الشخصية وبيانات صديقين لك.
  3. استخدم SELECT * FROM Friends; واعرض النتيجة.
