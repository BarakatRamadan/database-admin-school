تصنيفات أوامر SQL DDL · DML · DCL · TCL

فكّر زي المحترفين: مين بيغيّر الهيكل، ومين بيغيّر البيانات، ومين بيتحكم في الصلاحيات.

🎯 هتتعلم إيه في الدرس ده؟

  • الفرق بين DDL و DML و DCL و TCL.
  • الفرق العملي بين DELETE و TRUNCATE و DROP.
  • فهم COMMIT و ROLLBACK وأهمية الـ Transactions.

أوامر SQL بتتقسم لخمس عائلات رئيسية، وفهم الفرق بينها هيخليك تفكر باحترافية في أي عملية بتعملها.

🏗️ DDL — Data Definition Language

بتغيّر هيكل الجدول نفسه، وتُنفَّذ وتُحفظ فورًا (Auto-Committed).

الأمرالوظيفة
CREATEإنشاء جدول جديد
ALTERتعديل هيكل جدول موجود
DROPحذف الجدول بالكامل (هيكل + بيانات)
TRUNCATEحذف كل الصفوف مع الاحتفاظ بالهيكل
ALTER TABLE Students ADD Address VARCHAR(100);
DROP TABLE Employee;
TRUNCATE TABLE Employee;
تحذير: الفرق بين DELETE و TRUNCATE و DROPDELETE يحذف صفوفًا محددة ويمكن التراجع عنه. TRUNCATE يفرّغ الجدول بالكامل بسرعة، أصعب في التراجع. DROP يمسح الجدول نفسه من الوجود، هيكلًا وبياناتٍ، غالبًا بلا رجعة. من أشهر أسئلة مقابلات العمل!

✍️ DML — Data Manipulation Language

بتتعامل مع محتوى الجدول (البيانات نفسها).

INSERT INTO Students (FirstName, LastName) VALUES ('Sonoo', 'DBMS');

UPDATE Students
SET LastName = 'Sonoo'
WHERE StudentID = 3;

DELETE FROM Students WHERE StudentID = 3;
القاعدة الذهبيةأبدًا لا تكتب UPDATE أو DELETE بدون WHERE إلا وأنت متأكد 100%! نسيان WHERE يعني تطبيق الأمر على كل صفوف الجدول بلا استثناء. جرّب دايمًا بـ SELECT بنفس الشرط أولاً قبل التنفيذ الفعلي.

📖 DQL — Data Query Language

تحتوي أمرًا واحدًا فقط لكنه الأكثر استخدامًا في العالم: SELECT (شرحناه بالتفصيل في الدرسين 2 و3).

🔐 DCL — Data Control Language

تتحكم في من يقدر يفعل ماذا في قاعدة البيانات.

GRANT SELECT, UPDATE ON MyTable TO SomeUser;
REVOKE SELECT, UPDATE ON MyTable FROM SomeUser;

🔁 TCL — Transaction Control Language

تُستخدم مع أوامر DML لضبط "المعاملة" — مجموعة عمليات تُنفَّذ ككتلة واحدة إما تنجح كلها أو تفشل كلها.

DELETE FROM Customers WHERE Age = 25;
COMMIT;    -- تأكيد وحفظ التغيير بشكل دائم
ROLLBACK;  -- التراجع عن التغيير قبل تأكيده
معلومة إضافية: ACIDفكرة الـ Transactions أساسها خصائص ACID (Atomicity, Consistency, Isolation, Durability) — أساس ثقتك في أن قاعدة بيانات البنك لن تسحب فلوس من حسابك من غير ما تضيفها للطرف الآخر، حتى لو انقطعت الكهرباء أثناء التحويل!
الفئةالهدفأوامرها
DDLتعريف الهيكلCREATE, ALTER, DROP, TRUNCATE
DMLتعديل البياناتINSERT, UPDATE, DELETE
DQLاسترجاع البياناتSELECT
DCLالصلاحياتGRANT, REVOKE
TCLالمعاملاتCOMMIT, ROLLBACK, SAVEPOINT

تمرين تطبيقي

  1. أنشئ جدول Employee بالأعمدة EMP_ID (مفتاح أساسي)، EMP_NAME، PHONE_NO.
  2. أضف عمود Email جديد باستخدام ALTER.
  3. أدخل سجلين، ثم عدّل رقم هاتف أحدهما.
  4. جرّب حذف سجل باستخدام DELETE مع WHERE، بعد ما تتأكد بـ SELECT من الشرط.
