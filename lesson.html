DB Management SQL Server مستوى متوسط

حل مشكلة قاعدة البيانات العالقة في وضع Recovery Pending

ده نموذج لشكل الدرس النهائي على الموقع — هيتحط بدل الدروس الفعلية أول ما نبدأ ننشرها. كل درس هياخد نفس الشكل: مشكلة حقيقية، السبب، وخطوات الحل بالتفصيل.

المشكلة

قاعدة بيانات ظهرت بحالة Recovery Pending بعد إعادة تشغيل السيرفر فجأة، ومحدش قادر يوصل لها ولا حتى يشوف الجداول اللي جواها.

السبب المحتمل

غالبًا بيحصل بسبب مشكلة في ملفات الـ Log أو مساحة تخزين ممتلئة أثناء عملية استرجاع تلقائية (Automatic Recovery) لم تكتمل.

خطوات الحل

ALTER DATABASE [YourDB] SET EMERGENCY;
DBCC CHECKDB([YourDB]);
ALTER DATABASE [YourDB] SET SINGLE_USER WITH ROLLBACK IMMEDIATE;
DBCC CHECKDB([YourDB], REPAIR_ALLOW_DATA_LOSS);
ALTER DATABASE [YourDB] SET MULTI_USER;

مهم: خطوة REPAIR_ALLOW_DATA_LOSS ليها احتمالية فقد بيانات، فلازم يكون عندك نسخة احتياطية حديثة قبل ما تنفذها، وتتأكد إن مفيش حل تاني أرحم قبل ما تلجأ لها.

خلاصة

الدروس الحقيقية على الموقع هتتبني بنفس الأسلوب ده: مشكلة واجهناها فعلًا، تشخيص واضح، وخطوات حل مجربة — مش نسخ من التوثيق الرسمي بس.
