عنوان الدرس (هيتغير لاحقًا)

هنا مقدمة قصيرة تشرح إيه المشكلة أو المفهوم اللي الدرس ده هيغطيه، وليه مهم للـ DBA يعرفه.

الخطوات

وصف الخطوة الأولى، ومتبوعة بمثال كود لو محتاج.

RESTORE DATABASE MyDB
FROM DISK = N'D:\Backups\MyDB.bak'
WITH NORECOVERY;
ملاحظة: أي تحذير أو نقطة مهمة تتاخد بالها قبل تنفيذ الأمر ده تتحط هنا.
